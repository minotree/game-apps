# 타임 롱기누스 구현 진행표

## 5대 고유 스탯 월간 루프 (2026-11-02)

- 요청/문제: 기획 문서의 세계선별 5대 고유 스탯을 현재 임시 3개 수치로는 표현할 수 없었다.
- 변경: 3개 세계선의 5대 고유 스탯 계약과 초기값을 추가하고, 수련·알바·탐험이 현재 세계선의 해당 스탯만 바꾸도록 월간 규칙과 PWA 표시를 갱신했다. 이전 브라우저 임시 저장과 충돌하지 않도록 저장 키를 v2로 분리했다.
- 검증: `pnpm.cmd typecheck`, `pnpm.cmd test`, `pnpm.cmd build:time-longinus` 통과. 의존성 재연결 과정에서 손상된 기본 pnpm 캐시를 피해 `.pnpm-store-repair`를 사용했다.
- 사용자 확인: 브라우저·설치·캐시·토스·Android/iOS 기기 검증은 미실행이다.
- 적용: 로컬 코드·문서 변경만 수행했다.
- 남은 작업: 전직 조건과 활동별 해금 규칙, 직업 선택, 탐험/전투, 환생 규칙을 순서대로 구현한다.

## 멀티 게임 작업 공간으로 이동 (2026-11-02)

- 요청/문제: 이 게임을 포함한 여러 게임을 하나의 작업 공간에서 관리해야 한다.
- 변경: 프로젝트를 `games/time-longinus/`으로 이동하고, 루트 workspace에서 독립 게임으로 등록했다. 기획 문서 바로가기도 `games/time-longinus/docs/planning/`에 보존했다.
- 검증: `pnpm.cmd typecheck`, `pnpm.cmd test`, `pnpm.cmd build:time-longinus` 통과.
- 사용자 확인: 브라우저·설치·캐시·토스·Android/iOS 기기 검증은 미실행이다.
- 적용: 로컬 파일·설정·문서 변경만 수행했다.
- 남은 작업: 기획 문서의 상충하는 엔딩 명칭·조건을 구현 전에 별도 결정 문서로 확정한다.

## 프로젝트 지침 보완 (2026-11-02)

- 요청/문제: 프로젝트 지침에 `마무리하자` 요청의 권한 경계가 명시되지 않았다.
- 변경: `AGENTS.md`에 문서 정리·검증·보고의 범위와, 별도 승인이 필요한 Git·배포·운영 변경을 추가했다.
- 검증: `git diff --check` 통과.
- 사용자 확인: 없음.
- 적용: 로컬 문서 변경만 수행했다.
- 남은 작업: 없음.

## 신규 PWA 기반 구성 (2026-11-02)

- 요청/문제: 공통 개발 지침을 적용한 신규 멀티플랫폼 게임 프로젝트의 실행 가능한 최소 구조가 필요했다.
- 변경: pnpm workspace, React + Vite 웹 앱, `contracts`/`core` 패키지, 4주 스케줄 규칙·테스트, PWA 프로토타입 UI, 프로젝트 지침과 실행 문서를 추가했다.
- 검증: `pnpm.cmd install`, `pnpm.cmd typecheck`, `pnpm.cmd test`, `pnpm.cmd build`를 통과했다. `git diff --check`는 작업 마무리 시 실행한다.
- 사용자 확인: 브라우저 렌더링, 설치·캐시, 토스 기기, Android/iOS 기기 검증은 미실행이다.
- 적용: 로컬 변경만 수행했다. 외부 계정·호스팅·Supabase·토스 콘솔에는 연결하거나 배포하지 않았다.
- 남은 작업: PWA 설치·서비스 워커 정책, 세부 스탯/직업/전투/환생 규칙, 저장 형식 마이그레이션, 토스·하이브리드 독립 앱 구현.
