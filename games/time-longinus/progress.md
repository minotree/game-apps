# 타임 롱기누스 구현 진행표

## 시네마틱 프롤로그 강화 (2026-11-02)

- 요청/문제: 기존 프롤로그는 텍스트와 버튼만 있어 2154년 AI 침공의 위기감과 시간 송환의 규모를 전달하지 못했다.
- 변경: 크로노스 관제실·붕괴한 도시·적색 AI 위협을 담은 세로 배경 자산을 추가하고, 프롤로그를 위협 관측 → 아카샤 분석 → 타임 롱기누스 기동의 3개 통신 기록으로 구성했다. 장면별 크로노 메시지, 진행 표시, 송환 버튼을 추가했다.
- 검증: `pnpm.cmd typecheck`, `pnpm.cmd test`(4개 통과), `pnpm.cmd build:time-longinus` 통과.
- 사용자 확인: 프롤로그 화면의 실제 모바일 시각 검토와 생성 자산의 최종 아트 승인·권리 검토는 대기 상태다.
- 적용: 로컬 PWA 코드·생성 이미지·자산 기록만 변경했다. 생성 이력은 `docs/architecture/asset-provenance.md`에 남겼다.
- 남은 작업: 사용자 화면 검토 후 텍스트 분량·전환 속도·사운드·연출을 조정하고, 이미지 용량 최적화를 검토한다.

## 이미지 중심 제1세계선 홈 화면 (2026-11-02)

- 요청/문제: 메인 화면이 스탯·로그·스케줄 텍스트 패널만으로 구성되어 영웅을 육성하는 게임의 시각적 중심이 부족했다.
- 변경: 제1세계선의 어린 영웅과 수련장 배경을 중앙 장면으로 추가했다. 영웅 이름·직업·월간 상태를 장면 위에 겹치고, 육성 데이터·크로노 로그·스케줄을 아래의 반투명 관리 패널로 재배치했다.
- 검증: `pnpm.cmd typecheck`, `pnpm.cmd build:time-longinus`, `git diff --check` 통과. 규칙 변경은 없어 기존 core 테스트 범위에는 영향을 주지 않는다.
- 사용자 확인: 실제 스마트폰에서 영웅의 크기, 상태 패널 대비, 스크롤 길이를 검토해야 한다. 제2·3세계선의 홈 장면은 아직 없다.
- 적용: 로컬 PWA·생성 이미지·자산 출처 기록만 변경했다.
- 다음 작업: 제1세계선의 월간 요약과 진입 시점에 맞춘 제2·3세계선 장면을 추가한다.

## 전 화면 가로·세로 반응형 보완 (2026-11-02)

- 요청/문제: 스마트폰을 가로로 회전했을 때 긴 브리핑·결과 화면의 내용이나 버튼이 화면 높이를 넘어 잘릴 수 있고, 화면별 정보 배치가 일관되지 않았다.
- 변경: 타이틀, 프롤로그, 송환 브리핑, 제1세계선 홈, 주차별 결과 화면에 가로 모드 전용 배치를 추가했다. 가로에서는 프롤로그·주차 결과를 2열로 구성하고, 홈 화면은 영웅 장면을 화면 높이에 맞춰 유지한다. 모든 장면형 화면은 세로 스크롤을 허용해 짧은 가로 화면에서도 하단 조작을 보장한다.
- 검증: `pnpm.cmd build:time-longinus`, `git diff --check` 통과.
- 사용자 확인: 실제 Android/iOS 기기와 브라우저별 회전·안전 영역·터치 검증은 미실행이다.
- 적용: 로컬 PWA CSS만 변경했다.
- 다음 작업: 실제 기기 검토 뒤 가로 모드의 패널 밀도와 이미지 크롭 위치를 조정한다.

## 주차별 스케줄 장면 연출 (2026-11-02)

- 요청/문제: 스케줄을 진행하면 결과 로그와 수치만 즉시 표시되어, 영웅이 실제로 수련·알바·탐험·휴식하는 시간의 흐름이 느껴지지 않았다.
- 변경: 수련·알바·탐험·휴식에 대응하는 4개 가로형 장면을 추가하고, 스케줄 진행 시 1~4주차를 순서대로 표시하는 전용 결과 화면을 구현했다. 각 장면은 약 2.2초 뒤 다음 주차로 넘어가며, 사용자는 버튼으로 바로 넘기거나 마지막 결과를 확인할 수 있다. 상태 저장과 월간 로그 반영은 마지막 주차 이후에 수행한다.
- 검증: `pnpm.cmd typecheck`, `pnpm.cmd test`(8개 통과), `pnpm.cmd build:time-longinus`, `git diff --check` 통과.
- 사용자 확인: 실제 스마트폰에서 장면 전환 시간, 자산 용량, 텍스트 대비를 검토해야 한다. 생성 자산의 최종 아트·권리 검토는 대기 상태다.
- 적용: 로컬 PWA·생성 이미지·자산 출처 기록만 변경했다.
- 다음 작업: 주차별 결과가 끝난 뒤의 월간 요약과 제2세계선 자동 진입 규칙을 구현한다.

## 디자인 참조 방향 기록 (2026-11-02)

- 요청/문제: 육성 게임의 체감과 AI 침공 세계관의 연출 방향을 명확히 해야 했다.
- 변경: 사용자 제공 참조를 바탕으로 월간 육성·선택·엔딩 수집의 게임 감각, AI 위협·시간 송환의 SF 긴장감, 모바일 UI 원칙과 독창성 경계를 `docs/architecture/design-direction.md`에 기록했다.
- 검증: `git diff --check`를 통과했다.
- 사용자 확인: 참조 작품의 자산·대사·캐릭터·고유 명칭은 사용하지 않는다.
- 적용: 로컬 문서 변경만 수행했다.
- 남은 작업: 이후 화면·규칙 구현에서 이 방향을 구체적으로 적용한다.

## 프롤로그 연구소 장면 확장 (2026-11-02)

- 요청/문제: 2154년 AI 재앙을 알리는 기존 인트로만으로는 시간 송환 작전의 규모와 출발점이 충분히 전달되지 않았다.
- 변경: 붕괴한 도시 관측 → 아카샤 분석 → 크로노스 연구소의 시간 관문 → 첫 번째 차원문 개방의 4장면 프롤로그로 확장했다. 각 장면을 앞뒤로 넘길 수 있으며, 마지막 장면에서만 게임을 시작한다.
- 검증: `pnpm.cmd typecheck`, `pnpm.cmd test`(4개 통과), `pnpm.cmd build:time-longinus` 통과.
- 사용자 확인: 실제 스마트폰에서 장면별 텍스트 분량·넘김 속도·연출 강도를 확인해야 한다. 연구소 장면은 기획서의 크로노스 기지/시간 송환 설정을 시각적으로 구체화한 구현 확장이다.
- 적용: 로컬 PWA 코드·생성 이미지·자산 출처 기록만 변경했다. 이미지 용량 최적화와 최종 아트/권리 검토는 대기 상태다.
- 다음 작업: 사용자 화면 검토 뒤 장면 전환 효과, 사운드, 연구소의 인물/대사 연출을 조정한다.

## 첫 송환 경험 연결 (2026-11-02)

- 요청/문제: 프롤로그가 끝난 직후 기능 확인용 메인 터미널과 직업 카드가 표시되어, 오퍼레이터가 영웅을 송환하는 첫 플레이 감각이 끊겼다.
- 변경: 프롤로그 마지막에 `송환 대상 확인` 화면을 추가했다. 오퍼레이터의 역할, 10세 회귀, 제1세계선 목적지, 나노봇 크로노를 브리핑한 뒤 제1세계선 도착 화면에서 첫 계열을 고르게 한다. 계열 선택 뒤에만 일반 메인 터미널로 전환된다.
- 검증: `pnpm.cmd typecheck`, `pnpm.cmd test`(4개 통과), `pnpm.cmd build:time-longinus`, `git diff --check` 통과.
- 사용자 확인: 영웅의 이름·외형·개별 대사는 기획서에서 확정되지 않아 추가하지 않았다. 실제 스마트폰에서 텍스트 밀도와 버튼 배치를 확인해야 한다.
- 적용: 로컬 PWA 및 화면 흐름 문서만 변경했다.
- 다음 작업: 첫 계열 선택 직후의 세계선별 짧은 현지 도입, 4주 스케줄의 주차별 결과/월간 요약을 구현한다.
