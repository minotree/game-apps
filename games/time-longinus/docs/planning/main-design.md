## 게임 개요

2154년, 초지능 AI **아카샤**의 침공으로 멸망 위기에 놓인 인류를 구하는 SF 시공간 차원 교차 육성 시뮬레이션이다. 플레이어는 크로노스 저항 기지의 오퍼레이터가 되어, AI가 계산할 수 없는 이계의 정신력·마력·과거의 전술 지혜를 얻기 위해 영웅을 세 세계선으로 송환한다.

- 육성 기간: 10세부터 18세까지 8년, 96개월, 384주
- 기본 분배: 세계선당 32개월(128주)
- 핵심 루프: 최초 직업 선택 → 4주 스케줄 → 스탯/전직 → 탐험·전투 → 결전·엔딩 → 환생
- 결말: 27개 직업 융합 엔딩, 세계의 운명 분기, 7개 히든 엔딩

## 세계선 최초 진입

1. 영웅은 10세의 신체로 세계선에 도착한다.
2. 나노봇 도우미 **크로노**가 환경을 브리핑한다.
3. 3개 입문 계열 중 하나를 필수 선택한다.
4. 선택 직후 1단계 직업이 확정되고, 주력 스탯 +10과 해당 계열의 1단계 수련·알바가 해금된다.

## 세계선과 5대 고유 스탯

| 세계선 | 기초 신체 스탯 | 직업 특화 스탯 |
| --- | --- | --- |
| 제1세계선: 구주 무협 | 체력, 근력 | 내공, 검법, 경공 |
| 제2세계선: 이계 판타지/SF | 체력, 마력 기초 | 마도공학, 타이탄 동기화, 속성 감응 |
| 제3세계선: 과거 현대 | 체력, 기초 지능 | IT/해킹 지식, 첨단병기 숙련, 대중 명성 |

## 9개 전직 계열

| 세계선 | 계열 | 1단계 → 4단계 |
| --- | --- | --- |
| 무협 | 정파 검선 | 삼류 무객 → 일류 검사 → 화경/검강 형성 → 현경/검선 |
| 무협 | 마교 천마 | 삼류 마두 → 음공/혈마 고수 → 극마/마신 각성 → 천마/만류귀종 |
| 무협 | 기관/의술 | 약초꾼·기공생 → 명의·기계도인 → 신의·기관대가 → 천기인/시공기관 마스터 |
| 판타지 | 타이탄 마스터 | 견습 기사 → 아케인 나이트 → 타이탄 마스터 → 신성 마장기 드라이버 |
| 판타지 | 시공간 아크메이지 | 견습 마법사 → 엘리멘탈 마스터 → 대마도사 → 차원 아크메이지 |
| 판타지 | 마도연금술사 | 연금술 수습생 → 마도공학자 → 연금술 거장 → 사이보그 연금 마스터 |
| 현대 | 사이버 랭커 | C급 게이트 용병 → A급 게이트 헌터 → S급 랭커 → 인류의 수호자 |
| 현대 | 양자 해커 | 견습 화이트해커 → 2단계 명칭 미확정 → 총괄 아키텍트 → 양자 AI 지배자 |
| 현대 | 대중 총지휘관 | 신인 크리에이터 → 저항군 홍보관 → 글로벌 리더 → 세계 총지휘관 |

양자 해커 2단계 명칭은 원본 문서 간 표기가 달라 구현 전 별도 결정한다.

## 월간 스케줄과 크로노

- 1개월은 4주다.
- 권장 안전 패턴은 수련/알바/탐험 3주 + 휴식 1주다.
- 스트레스가 80/100을 넘으면 질병·실패 위험이 생긴다.
- 휴식은 스트레스를 약 30~50 낮춘다.
- 크로노는 기연 힌트와 원클릭 추천 스케줄을 제공한다.

## 전투

탐험 중 발생하는 전투는 실시간 액션이 아닌 텍스트·선택지 기반 턴제다.

- 적은 물리(적), 마도(청), 전자(녹) 3색 쉴드를 가진다.
- 일치 속성 공격으로 쉴드를 깨면 Break 상태가 되어 큰 피해를 준다.
- 3개 세계선의 3·4단계 전직 완성 후 삼중 융합 필살기를 사용할 수 있다.

## 환생과 엔딩

### 영혼 공유 스탯

정신력, 영혼 통찰, 시공간 적응력, 전술 지휘로 구성된다. 세계선 Peak 스탯의 일부가 다음 회차에 귀속되어 기초 보정, 수련 가속, 기연·전투 보정에 쓰인다.

### 환생 보너스 포인트

엔딩 성과에 따라 50~100pt를 받고, 새 회차 시작 때 각 세계선의 기초 스탯에 수동 배분한다.

### 결말 판정

직업 조합(3 × 3 × 3), 아카샤 결전 성패와 최종 스탯, 특수 조건을 함께 판정한다.
