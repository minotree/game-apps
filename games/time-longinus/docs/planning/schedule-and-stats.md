# 27개 융합 엔딩 육성 스케줄 및 스탯 가이드 — 로컬 스냅샷

원본: [Google Docs](https://docs.google.com/document/d/1a0Ei9KzrCkczi6N2QN_BpNdIXQu-KQNofyQkHmMqkWI)  
동기화 기준일: 2026-11-02 (Asia/Seoul)

## 전직 단계와 목표

| 단계 | 주력 스탯 목표 | 추가 조건 |
| --- | --- | --- |
| 1단계 | Cap 100 | 최초 진입 시 계열 선택, 기초 수련/알바 해금 |
| 2단계 | 주력 스탯 100 | 1차 승급 시련 |
| 3단계 | 주력 스탯 250 | 2차 승급 시련 |
| 4단계 | 주력 스탯 500 | 공유 스탯 조건과 3차 승급 시련 |

`Cap 999`는 4단계 신화 단계의 최종 성장 한계를 뜻한다. 승급 시련의 상세 규칙은 구현 전에 별도 결정해야 한다.

## 96개월 기본 배분

| 기간 | 세계선 | 목표 |
| --- | --- | --- |
| 1~32개월 | 구주 무협 | 1~4단계 완성 |
| 33~64개월 | 이계 판타지/SF | 1~4단계 완성 |
| 65~96개월 | 과거 현대 | 1~4단계 완성 후 최종 결전 준비 |

## 스트레스와 3+1 패턴

- 안전선: 스트레스 80/100 미만 유지
- 1~3주차: 주력 수련 2회 + 알바 1회
- 4주차: 휴식/바캉스
- 크로노 추천 스케줄은 이 안전 루프를 자동 편성한다.

## 대표 육성 예시

정파 검선 계열의 예시 목표는 다음과 같다.

| 기간 | 목표 |
| --- | --- |
| 1~8개월 | 검법 100, 내공 80, 근력 50; 무관 비재 통과 |
| 9~20개월 | 검법 250, 내공 200, 체력 150; 문주 대결 통과 |
| 21~32개월 | 검법 500, 내공 450, 경공 300; 검선 시련 통과 |

이 가이드는 전체 27개 조합을 무협 계열 3개 × 판타지 계열 3개 × 현대 계열 3개로 설명한다. 각 조합의 상세 서사와 기술명은 [fusion-endings.md](fusion-endings.md)를 함께 본다.
