# PRD/TRD 및 사용자 흐름 v3 — 로컬 스냅샷

원본: [Google Docs](https://docs.google.com/document/d/1lDOv0D-hD_i_s2MVaWTy2dRGPETAAuEiqTuP0myTPoA)  
동기화 기준일: 2026-11-02 (Asia/Seoul)

## 제품 목표

레트로 텍스트/UI 감성의 8년 차원 교차 육성 게임을 PWA → 토스 미니앱 → Capacitor 기반 하이브리드 앱 순서로 제공한다.

## 핵심 기능

1. 월간 4주 스케줄러와 DOS풍 타자기 결과 연출
2. 세계선별 5대 고유 스탯, 영혼 공유 스탯, 환생 보너스 포인트
3. 크로노 기연 힌트와 원클릭 추천 스케줄
4. 3색 쉴드 Break 기반 텍스트 턴제 전투와 삼중 융합 필살기
5. 로컬 오프라인 저장, 이후 토스 SDK의 결제·공유 연동

## 화면 흐름

### 회차 시작

```text
타이틀
  → 새 게임 또는 환생 재시작
  → (환생 회차만) 환생 포인트 배분
  → 차원 송환
  → 메인 스케줄 화면
```

환생 포인트 배분 화면에서는 3개 세계선 탭을 바꾸며 기초 스탯에 포인트를 배정한 뒤 송환을 확정한다.

### 메인 터미널

| 영역 | 구성 |
| --- | --- |
| 상단 | 현재 세계선, 자금, 스트레스 게이지 |
| 중앙 | 캐릭터 표현, 5대 고유 스탯, 공유 스탯, 크로노 힌트 |
| 하단 | 4주 스케줄 슬롯, 편성, 진행 버튼 |

스케줄 진행은 1주차부터 4주차까지 순서대로 결과를 출력한다. 각 주차에서 성공/실패, 스탯 변화, 자금 획득, 돌발 이벤트를 보여주고, 4주차 휴식 뒤 월간 요약을 보여준 뒤 메인으로 돌아간다.

### 전투

```text
탐험 중 적 조우
  → 적 HP / 물리·마도·전자 쉴드 확인
  → 기본 공격·전직 기술·회복/결계·융합기 선택
  → 속성 쉴드 파괴 및 Break
  → 승리 보상 또는 실패 처리
```

## 기술 방향

- 현재 프로젝트는 React + Vite 기반 PWA 프로토타입으로 시작한다.
- UI와 플랫폼 SDK는 각 앱이 소유하고, 게임 규칙은 플랫폼 독립 `core`에 둔다.
- 실제 PWA 설치/서비스 워커, 토스 SDK, Capacitor는 각 개발 단계에서 공식 문서와 설치 버전을 재확인해 추가한다.
- 원본 TRD에 예시로 제시된 특정 프레임워크·상태 라이브러리는 현재 구현의 고정 요구사항이 아니다.
