## 구조

최종 직업은 무협 3개 × 판타지 3개 × 현대 3개의 조합이며 총 27개다. 각 조합은 전용 캐릭터 콘셉트, 삼중 융합기, 엔딩 서사를 가진다. 아카샤 결전 성패와 최종 스탯에 따라 같은 조합 내에서도 구원·수호·비극 등의 분기가 추가된다.

## 구현용 판정 데이터

1. 세 세계선의 선택 직업과 최종 단계가 확정되면 조합 키를 만든다.
2. 조합 키로 엔딩 제목·융합기·서사·이미지 자산을 찾는다.
3. 아카샤 전투 결과와 최종 스탯으로 세부 결말 분기를 선택한다.
4. 히든 엔딩 조건을 먼저 검사하고 충족 시 일반 27개 엔딩보다 우선한다.

정확한 영문명·전용 융합기·서사 전문은 Google Docs 원본을 기준으로 하며, 실제 엔딩 콘텐츠 구현 전 데이터 파일로 정규화한다.
