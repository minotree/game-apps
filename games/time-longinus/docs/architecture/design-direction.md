# 디자인 방향과 참조 범위

## 사용자 제공 참조

- 고전 육성 게임 **프린세스 메이커**: 월간 육성 스케줄, 능력치의 누적 성장, 선택의 결과, 다양한 엔딩으로 이어지는 플레이 감각
- 영화 **터미네이터**: 압도적인 AI 위협, 멸망 직전의 인류, 시간을 건 작전이 주는 SF 긴장감

## 타임 롱기누스에 적용할 원칙

### 육성 경험

- 한 달 4주를 수련·알바·탐험·휴식으로 배정한다.
- 매 선택이 스탯·스트레스·크레딧·직업 성장에 남는 결과를 만든다.
- 크로노는 초보자를 돕되 플레이어의 전략적 선택을 대신하지 않는다.
- 직업·세계선·전투 성과의 조합이 다회차 엔딩 수집 동기를 만든다.

### 세계관과 연출

- 2154년 크로노스 기지와 아카샤의 침공을 통해 위기감 있는 프롤로그를 만든다.
- 세 세계선에서 얻은 힘을 결합해 AI가 계산할 수 없는 해법을 만든다는 것이 핵심 서사다.
- 레트로 터미널 감성을 쓰되, 모바일 세로 화면에서 읽기 쉬운 카드·큰 터치 영역·명확한 상태 표시를 우선한다.

## 권리와 독창성 경계

참조 작품의 게임 구조와 장르적 정서는 영감으로만 사용한다. 등장인물, 고유 명칭, 대사, 음악, 이미지, UI 자산, 화면 구도, 세부 서사를 복제하지 않는다. 타임 롱기누스의 인물·세계관·직업·시스템·시각 자산은 독자적으로 만든다.
