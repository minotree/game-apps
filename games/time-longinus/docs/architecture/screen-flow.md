# 화면 흐름 기준

## 새 게임

```text
타이틀
  → 2154년 크로노스 기지 프롤로그
  → 송환 대상 확인 / 크로노스 연구소 브리핑
  → 제1세계선 최초 진입 / 크로노 현지 브리핑 / 직업 선택
  → 메인 터미널: 월간 4주 스케줄
  → 탐험 중 전투
  → 엔딩 / 환생
```

## 환생 회차

```text
타이틀
  → 환생 보너스 포인트 배분
  → 제1세계선 차원 송환
  → 메인 터미널
```

새 게임과 환생 회차의 최초 진입 세계선은 항상 제1세계선이다. `작전 계속`만 로컬 저장에 기록된 마지막 세계선을 유지한 채 메인 터미널로 돌아간다.

## 메인 터미널 구성

1. 상단: 세계선, 월, 크레딧, 스트레스
2. 중앙: 직업 단계, 5대 고유 스탯, 공유 스탯, 크로노 힌트
3. 하단: 4주 스케줄과 진행 버튼
4. 진행 후: 주차별 결과와 월간 요약

현재는 새 게임의 타이틀·프롤로그·최초 직업 선택·기본 스케줄까지 구현했다. 환생 포인트, 공유 스탯, 탐험 전투, 월간 요약은 이후 화면으로 추가한다.
