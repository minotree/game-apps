# 세계선 시작 및 이어하기 기준

- 결정일: 2026-11-02
- 새 게임: 언제나 제1세계선에서 시작한다.
- 환생 회차: 환생 보너스 포인트 배분 뒤 언제나 제1세계선으로 송환한다.
- 최초 계열 선택 전에는 제2·3세계선으로 전환하거나 해당 세계선의 계열을 선택할 수 없다.
- 현재 PWA는 세계선 수동 전환 버튼을 제공하지 않는다. 제2·3세계선은 제1세계선의 정해진 육성 구간을 마친 뒤 자동 진입시키는 규칙을 구현할 때 처음 노출한다.
- 작전 계속: 새 게임 시작 규칙을 다시 적용하지 않는다. 로컬 저장의 마지막 세계선과 모든 진행 상태를 그대로 복원한다.
- 구현 상태: 새 게임은 `createInitialGame()`의 제1세계선 상태로 생성되며, 이어하기는 저장된 `worldline`을 유지한다. 환생 기능은 아직 구현 전이다.
