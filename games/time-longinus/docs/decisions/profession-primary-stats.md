# 최초 직업의 주력 스탯 매핑

## 결정 (2026-11-02)

세계선 최초 진입 시 직업 하나를 선택하며, 기획의 “주력 스탯 +10”은 다음 스탯에 적용한다. 이후 1단계 수련 보정도 같은 주력 스탯에 적용한다.

| 세계선 | 계열 | 주력 스탯 |
| --- | --- | --- |
| 구주 무협 | 정파 검선 | 검법 |
| 구주 무협 | 마교 천마 | 내공 |
| 구주 무협 | 기관 / 의술 | 체력 |
| 이계 판타지/SF | 타이탄 마스터 | 타이탄 동기화 |
| 이계 판타지/SF | 시공간 아크메이지 | 속성 감응 |
| 이계 판타지/SF | 마도연금술사 | 마도공학 |
| 과거 현대 | 사이버 랭커 | 첨단병기 숙련 |
| 과거 현대 | 양자 해커 | IT/해킹 지식 |
| 과거 현대 | 대중 총지휘관 | 대중 명성 |

## 근거와 범위

기획의 세계선별 5대 스탯과 각 계열의 반복적인 성장·전직 조건 설명을 기준으로 한 구현 결정이다. 전직에 필요한 보조 스탯, 활동 이름과 수치, 승급 시련 조건은 이후 별도 결정으로 추가한다.
